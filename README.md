**SPICY HUT RESTAURANT**

Spicy Hut is a simple and user-friendly restaurant website with an online food ordering feature.

The project includes a restaurant landing page, menu/order interface, and a Node.js + Express backend that processes customer orders.

**FEATURES**

- Restaurant landing page
- Food ordering interface
- Customer order form
- Order submission and processing
- Order confirmation message
- Node.js and Express backend
- Orders stored locally in JSON format
- Simple and responsive user interface

**TECHNOLOGIES USED**

**FRONTEND**

- HTML5
- CSS3
- JavaScript

**BACKEND**

- Node.js
- Express.js

**DATA STORAGE**

- JSON (`orders.json`)
